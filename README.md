# dotfiles

> **Ex frustratione, creatio.**  
> *(Out of frustration, creation.)*

My personal Linux desktop and application configurations.

This repository contains the configuration files I maintain for my daily environment, covering window compositors, terminal applications, shell utilities, editors, and other desktop components.

The configurations reflect my own workflow and preferences, developed through experimentation, refinement, and the occasional frustration with existing defaults.

They are primarily maintained for my own systems rather than as a ready-made desktop environment. Individual components may nevertheless be reused or adapted where appropriate.
